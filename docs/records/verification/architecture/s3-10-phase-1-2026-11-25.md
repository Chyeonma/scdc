# S3-10 bước 1 tách cấu trúc và host Community

Bước 1 chia code Community thành các project riêng và dựng host chạy thử với database sạch. Host chung tiếp tục phục vụ chức năng hiện tại; host mới giữ readiness 503 tới khi hoàn thiện các tích hợp service ở bước 2.

**Trạng thái:** đã triển khai và kiểm chứng phạm vi bước 1 ngày 2026-11-25. S3-10 chưa hoàn tất; dữ liệu và gateway dev chưa chuyển.

Interface và DTO chuyển vào Application; model và bộ tính quyền vào Domain. Implementation gắn SQL/transaction nằm ở Infrastructure. Namespace và hành vi hiện hành giữ tương thích. Các controller và bộ lọc OpenAPI được biên dịch từ cùng nguồn bởi API chung và API Community; host mới không tham chiếu assembly API chung hoặc implementation Messaging/Identity.

## Host và giới hạn ở bước 1

| Kiểm tra trên container thật | Kết quả |
|---|---|
| `GET /health/live` | 200, mode `preparation`, `workersEnabled=false` |
| `GET /health/database` | 200 với database Community riêng và role runtime |
| `GET /health/ready` | 503 `COMMUNITY_INTEGRATIONS_NOT_CONFIGURED` |
| `POST /api/v1/servers` | 503 trước khi xác thực hoặc ghi dữ liệu |
| Swagger Community | 200; chỉ có các route Community |
| Khởi động lại API | Liveness/database tiếp tục 200; readiness tiếp tục 503 |

Gate kiểm tra action đã được routing chọn, gồm đường dẫn khác cách viết hoa. Hai worker Community vẫn có code và đăng ký dùng được trong host chung; host chuẩn bị không bật chúng. Adapter Messaging đang thiếu luôn báo không sẵn sàng, không tạo provision result hoặc fence receipt giả.

Profile `community-preview` có instance PostgreSQL riêng phục vụ thử nghiệm; nó không thay quyết định v1 dùng database Community trên instance chung với Messaging. API chỉ được cấp runtime password và public JWT key thử. Private key JWT thử không lưu lại sau khi tạo public key; không lấy khóa Identity dev.

## Dữ liệu và quyền

[Baseline](../../../../database/postgres/community/README.md) tạo 21 bảng Community, extension tìm kiếm, hàm, trigger, index và constraint cục bộ. Dữ liệu khởi tạo chỉ gồm sáu permission và tám dòng ledger checksum; các bảng nghiệp vụ rỗng.

Test đối chiếu danh sách cột/kiểu/nullability của baseline với schema nguồn sạch, kiểm tra không có FK tới owner khác. Role runtime không có quyền tạo schema/object, sửa ledger, xóa fence hay sửa/xóa receipt. Database health từ chối role administrator hoặc database còn schema Identity/Messaging.

Các script baseline chỉ dành cho database mới. Công cụ chuyển dữ liệu thật, đối chiếu catalog legacy, giữ công việc dở dang và diễn tập phục hồi thuộc bước chuyển dev sau này.
