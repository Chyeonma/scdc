## Phạm vi và lệnh thực hiện

Identity dùng instance `identity-postgres`, admin `scdc_identity_admin`, runtime
`scdc_identity`, database `scdc_identity`. Source `scdc_chat` tiếp tục giữ
Community/Messaging và bản dữ liệu Identity cũ bị khóa runtime. Chỉ Identity
nhận runtime password file mới; admin secret chỉ cấp DB/job, không cấp API.

[Baseline và CLI thật](../../../../database/postgres/identity/README.md) mô tả
`identity-transfer --engine podman --source-container ... --target-container ...
--artifact-directory ... --quiesced` và mode `--rollback-before-writes`.
Connection admin nguồn/đích chỉ qua biến môi trường private, không vào argv/log.
CLI kiểm đúng instance/OID/database qua Npgsql và container, version/checksum,
role/client, advisory lock và table SHARE lock trước dump owner.

Manifest source/target của mỗi lần chuyển khớp toàn bộ giá trị bằng SHA-256
hàng JSON sắp ổn định với timezone UTC, số dòng và schema fingerprint; gồm
security stamp, hash mật khẩu/token, session expiry/revocation/rotation,
outbox/inbox/lease, scope/version/epoch, journal/ACK/publication và audit.
Sequence `last_value/is_called` khớp trước khi startup worker. Một biểu thức
CHECK email trong bootstrap MVP được PG18 gộp AND sau parse; chỉ chuẩn hóa đúng
biểu thức tương đương đã rà, không bỏ qua cấu trúc hay khác biệt dữ liệu.

## Chuyển dev và kết luận

Chưa mở writer Identity đích ở dev tại mốc lập hồ sơ này. Trước chuyển sẽ đóng
request/writer cũ, tạo backup mới gồm DB/roles, Redis AOF, khóa/cấu hình và image,
đối chiếu khi writer dừng, rồi mới mở host đích. Source phải tiếp tục `NOLOGIN`;
Identity startup có thể đổi Redis generation ngay trước request đầu tiên nên
phục hồi sau đó cần sửa tiến hoặc reconciliation.

Sau chuyển bổ sung thời điểm mở ghi, số dòng/sequence thực tế, `make check`,
browser/trace/restart và trạng thái PR/CI. Việc tách Messaging/Community database,
worker email thật và production backup không thuộc S3-03.
