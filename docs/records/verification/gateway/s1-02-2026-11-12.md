## Thay đổi và lỗi được xử lý

- Nginx ưu tiên route API, Hub và Swagger trước regex asset. Các đường dẫn API kết thúc bằng `.js` hoặc `.css` được API trả lỗi JSON đúng mã thay vì bị xử lý như file tĩnh.
- Cấu hình dùng template và DNS lấy từ container; cache resolver 5 giây cho phép kết nối lại sau khi API đổi IP mà không restart Nginx.
- Gateway giữ prefix, query, Host và cấu hình HTTP/1.1, Upgrade cho SignalR; hỗ trợ WebSocket, SSE và Long Polling. Gateway không tự retry upstream.
- Route Hub không ghi access log; error log giữ mức critical để lỗi upstream không ghi URL chứa token ở mức error thông thường.
- Mount SQL dùng nhãn SELinux chia sẻ `z` để PostgreSQL đọc được bootstrap trên Podman. Lượt thử đầu dừng ở lỗi permission; đã sửa trước lần chạy đạt.
- Sửa cấu hình Playwright: worker không có tham số `--project` của runner nên không chạy lại bước kiểm tra CLI. Lượt thử thứ hai đã phát hiện lỗi này; lần chạy đạt bên dưới dùng cấu hình đã sửa.

## Kết quả

Lệnh nghiệm thu, sau khi `npm ci` đã chạy thành công:

```bash
SCDC_E2E_BROWSER_CHANNEL=chrome python3 scripts/test_gateway.py --engine podman
```

Máy chạy không có Node trong PATH mặc định nên dùng Node/npm từ image Playwright chính thức đã có, chép vào thư mục tạm. Cách chạy thông thường cho thành viên có Node.js 24 là `make test-gateway ENGINE=podman` theo [hướng dẫn](../../../guides/development.md#gateway).

| Ca đã chạy | Kết quả thực tế | Trạng thái |
|---|---|---|
| SPA, asset, API và query | HTML không cache; asset immutable; SPA fallback hoạt động; API giữ HTTP 400/401/404 và JSON, query `limit=0` được kiểm tra | Đạt |
| Negotiate | Không có token trả 401; phiên hợp lệ trả 200 và ba transport | Đạt |
| WebSockets | Đăng ký đúng hội thoại và nhận tin DM đã lưu qua Nginx | Đạt |
| Server-Sent Events | Ép transport SSE và nhận đúng tin DM qua Nginx | Đạt |
| Long Polling | Ép transport Long Polling và nhận đúng tin DM qua Nginx | Đạt |
| Restart và đổi IP API | Hai trang chat kết nối lại, giữ tin cũ và nhận tin mới. IP cũ được giữ bằng container thử để buộc API đổi IP; ID container Nginx không đổi. Log không chứa `access_token=` hoặc access token của hai phiên thử | Đạt |
| Community và DM trong trình duyệt | Gửi nhận giữa hai phiên, chuyển Community rồi quay lại DM vẫn thấy lịch sử | Đạt |
