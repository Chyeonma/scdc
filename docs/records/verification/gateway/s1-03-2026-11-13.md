## Kết quả thực thi

Lệnh chạy bộ gateway:

```bash
SCDC_E2E_BROWSER_CHANNEL=chrome make test-gateway ENGINE=podman
```

Máy thực thi dùng Node/npm lấy từ image Playwright có sẵn vào thư mục tạm trong PATH, như lần kiểm chứng S1-02. Script đã build stack từ đầu, khởi tạo dữ liệu và khóa riêng, rồi dọn container và volume thử sau khi đạt.

| Ca S1-03 | Kết quả quan sát | Trạng thái |
|---|---|---|
| JSON từ service mẫu | `GET /health?probe=s1-03` trả 200, application/json, `service=sample-service`, `status=healthy`, timestamp mới; Cache-Control no-store. POST trả 405. `/healthz` và `/api/v1/health` vẫn trả kết quả riêng | Đạt |
| Monolith dừng | `/health` vẫn trả 200 từ service mẫu, `/api/v1/health` trả 502; giao diện vẫn trả 200. Sau đó monolith được khởi động lại thành công | Đạt |
| Service mẫu dừng và đổi IP | `/health` trả 502 khi sample dừng; monolith và giao diện vẫn trả 200. Giữ IP cũ bằng container thử rồi tạo lại sample với IP khác: `/health` phục hồi, ID container Nginx không đổi | Đạt |
