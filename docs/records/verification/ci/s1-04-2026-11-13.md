## Phần còn phải nghiệm thu trên GitHub

Phiên làm việc chưa có kết nối GitHub được xác thực. Chưa đẩy nhánh, tạo PR kiểm chứng hoặc thay đổi ruleset của repository.

Sau khi có kết nối, thực hiện [quy trình nghiệm thu](../../../guides/continuous-integration.md#nghiệm-thu-s1-04-trên-github): lưu link run xanh, PR có test cố ý hỏng, run đỏ, bằng chứng check `CI` bắt buộc chặn merge và run xanh sau khi hoàn tác assertion. Người review xác nhận theo thẻ trước khi merge thay đổi CI.
