# S1-08 — Bộ lệnh dựng môi trường ngày 2026-11-17

Hồ sơ ghi kết quả thiết kế lại [Makefile](../../../../Makefile), tự khởi tạo khóa trong Compose và kiểm chứng [hướng dẫn dựng môi trường](../../../guides/development.md#setup).

**Trạng thái:** đã triển khai và kiểm chứng local; chờ Vg và Sáng tự làm theo để xác nhận kiểm tra chéo.

## Cách dựng môi trường

- `make setup` tạo `.env` khi chưa có, kiểm tra cấu hình, build, chạy stack và kiểm tra sau khởi động. Khóa Community không in ra terminal; `.env` hiện hữu không bị ghi đè.
- Compose dùng job `messaging-keygen` để tạo khóa DM, cùng job JWT đã có. API chờ cả hai job thành công; khởi tạo lặp giữ nguyên khóa.
- `make up` chạy lại stack; `make build` build image; `make check` kiểm tra health, PostgreSQL và Nginx; `make status`, `make logs`, `make down` phục vụ thao tác thường ngày. `down` giữ volume.
- Tùy chọn `ENGINE=podman`, `ENV_FILE` và `COMPOSE_ARGS` được truyền nhất quán tới các lệnh. Hướng dẫn và mẫu PR đã cập nhật để không gọi các target được bỏ.
- Giữ các lệnh kiểm tra và đồng bộ tài liệu độc lập với thao tác dựng môi trường. Kiểm thử backend, frontend, gateway và giám sát có lệnh trực tiếp trong hướng dẫn, với yêu cầu môi trường thử riêng.

## Môi trường và bằng chứng

Nhánh `docs/s1-08-minimal-setup`, nền `d503d5f` cùng thay đổi S1-08 trong working tree. Linux, Podman với provider Docker Compose v5.6.0; image nền và cache build có sẵn. Lần chạy dùng project riêng `scdc-s1-08-make-20261117t103330z`, file môi trường riêng ban đầu chưa tồn tại, và các volume mới; giữ nguyên cổng 3000, 5026, 5432 và 5080.

Trình điều khiển local `artifacts/s1-08/verify-make.py` gọi đúng các target `setup`, `status`, `logs`, `down`, `up`, `check`; gọi HTTP qua gateway để thử nghiệp vụ và Search API để tìm dữ liệu giám sát. Mỗi lệnh Make nhận `ENGINE=podman`, `ENV_FILE=<file-thử>` và `COMPOSE_ARGS=-p <project-thử>`. Không dùng file môi trường hoặc volume của stack phát triển hiện hữu.

Kết quả tại `artifacts/s1-08/20261117T103330Z/`: `result.json` ghi **12/12 mục đạt**, `passed=true`, `cleanup_exit_code=0`. Log riêng gồm lần setup đầu, setup lặp, trạng thái và log container, dừng/chạy lại và kiểm tra sau khởi động. File môi trường thử được xóa sau khi dọn stack; báo cáo không ghi khóa, mật khẩu hay token.

## Kết quả thực thi

| Phần | Kết quả |
|---|---|
| Dựng lần đầu | `make setup` tạo `.env`, build image, tạo khóa DM/JWT, khởi chạy và tự kiểm tra stack thành công |
| Dựng lại | Lần `make setup` thứ hai đạt; nội dung `.env`, khóa DM, private/public key JWT giữ nguyên |
| Gateway | Giao diện, health Nginx, health API, health service mẫu và OpenAPI JSON trả HTTP 200 |
| PostgreSQL và Nginx | Các lệnh `pg_isready` và `nginx -t` trong `make check` đạt |
| Trạng thái và log | `make status`, `make logs` chạy được; hai job tạo khóa thoát mã 0 |
| Tài khoản và JWT | Hai tài khoản đăng ký, xác minh, đăng nhập được; endpoint mẫu nhận token thật, thiếu token trả 401 |
| DM | Gửi được tin; gửi lại cùng mã không tạo tin mới; người nhận đọc được lịch sử |
| Giám sát | Health OpenObserve đạt; trace ID trong hướng dẫn xuất hiện ở cả Logs và Traces, stream `scdc`, service `scdc-sample` |
| Dừng và chạy lại | `make down`, `make up`, `make check` đạt; tài khoản, tin nhắn và khóa còn nguyên; token cũ vẫn dùng được |
| Dọn stack thử | Project và volume thử đã dọn, mã thoát 0 |

Kiểm tra bổ sung trên thư mục tạm xác nhận `make init` tạo khóa 32 byte với quyền file 0600, không lộ khóa trong output, giữ nguyên cấu hình khi chạy lại và giữ cả file cấu hình hiện hữu thiếu khóa. Khi Compose trả lỗi ở bước kiểm tra cấu hình, `make setup` dừng trước khởi chạy và kiểm tra health.

20 test công cụ đồng bộ tài liệu đạt, gồm truyền tham số qua Make và tránh diễn giải tham số nguồn thành lệnh shell. Cả 28 đoạn shell trong hướng dẫn được kiểm tra cú pháp bằng Bash và zsh. `make docs-check` và `git diff --check` đạt.

## Phần còn cần xác nhận

- Vg và Sáng tự dựng theo hướng dẫn để hoàn tất kiểm tra chéo.
- Docker Engine, Docker Desktop và Windows/WSL chưa được chạy thử trong lần này; chưa thử tải image/dependency trên hệ điều hành mới cài.
- Luồng DM lần này kiểm tra qua HTTP; không chạy lại bộ trình duyệt và realtime.
