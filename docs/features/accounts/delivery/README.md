# SCDC — Bàn giao tài khoản

Gói MVP-ID và phân công tại [hồ sơ MVP](../../../releases/mvp.md#packages); phạm vi hoàn thiện tại [v1](../../../releases/v1.md). Chọn UC/AC từ [đặc tả](../specs/README.md), đối chiếu khoảng trống ở [status](../status.md), rồi khóa scope/thiết kế theo gói.

Thư mục này chưa có kế hoạch hoặc hồ sơ nghiệm thu riêng cho gói tài khoản. Khi một gói có scope, tạo `<gói>/plan.md`; kết quả chạy gắn commit vào `<gói>/acceptance.md` theo [mẫu hồ sơ](../../../templates/release-record.md).
