# SCDC — Bàn giao media

Media được triển khai theo V1-MEDIA-01–05 tại [hồ sơ v1](../../../releases/v1.md#gói-media-sau-nền-mvp). Scope và người phụ trách được quản lý tại hồ sơ mốc; [thiết kế](../design/README.md) và [AC/TC](../specs/acceptance.md) giữ điều kiện cần đáp ứng.

Chưa có hồ sơ nghiệm thu media/provider trong thư mục này. Mỗi gói khi được chọn ghi `<gói>/plan.md`; kết quả gắn commit/provider build/môi trường vào `<gói>/acceptance.md` theo [mẫu](../../../templates/release-record.md), rồi dẫn từ [status](../status.md).
