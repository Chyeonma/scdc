# Sổ quyết định và vấn đề cần làm rõ

> Tài liệu gốc đầy đủ: [SCDC-LOG-001](../archive/project-specs/01-initiation/03-discovery-and-decision-log.md)

Tài liệu này chứa toàn bộ 59 quyết định (DEC-001 → DEC-059) và 13 vấn đề mở (OQ-001 → OQ-013) của dự án.

Do nội dung rất dài và cần giữ nguyên tính chính xác, vui lòng đọc trực tiếp file gốc:

👉 **[Mở sổ quyết định đầy đủ](../archive/project-specs/01-initiation/03-discovery-and-decision-log.md)**

## Tra cứu nhanh theo chủ đề

| Chủ đề | Quyết định liên quan |
|---|---|
| **Tài khoản** | DEC-036, DEC-041, DEC-042, DEC-051, DEC-054 |
| **Nhắn tin DM** | DEC-016–021, DEC-035, DEC-037, DEC-052, DEC-053 |
| **Cộng đồng** | DEC-022–029, DEC-031–034, DEC-038–040, DEC-043–045 |
| **Phân quyền** | DEC-055–058 |
| **Thoại/Video** | DEC-046–050 |
| **Giao diện** | DEC-059 |
| **Quy trình** | DEC-030 (không khảo sát ngoài đợt này) |
