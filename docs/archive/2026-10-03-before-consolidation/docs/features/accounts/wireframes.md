# Tài khoản — Wireframes

> Tài liệu gốc: [SCDC-UX-DM-001](../../archive/project-specs/04-ux/02-account-dm-wireframes.md)

Các phác thảo giao diện tài khoản (đăng ký, đăng nhập, xác minh, đặt lại mật khẩu, hồ sơ) được mô tả chi tiết trong file gốc.

👉 **[Xem wireframes đầy đủ](../../archive/project-specs/04-ux/02-account-dm-wireframes.md)**

Các trạng thái giao diện cần thiết kế:
- Đăng ký: form, lỗi validation, trùng tên tài khoản
- Đăng nhập: form, sai mật khẩu, chưa xác minh
- Xác minh email: thành công, hết hạn, đã dùng
- Đặt lại mật khẩu: gửi yêu cầu, nhập mật khẩu mới, thành công
- Hồ sơ: xem, sửa tên hiển thị
