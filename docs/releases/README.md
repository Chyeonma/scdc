# SCDC — Mốc bàn giao

| Mốc | Phạm vi | Hồ sơ |
|---|---|---|
| MVP | Identity, Community và DM trong một API host Modular Monolith | [MVP](mvp.md) |
| v1 | Microservice, hoàn thiện tính năng nền, thoại/video/chia sẻ màn hình | [v1](v1.md) |

DEC-114/116 xác định hai mốc. Hoàn thành MVP không đồng nghĩa đạt toàn bộ tiêu chí v1 hoặc được phép mở đăng ký công khai. `v1` sản phẩm và prefix API `/api/v1` là các định danh khác nhau.

Release chọn UC/AC và gate; hành vi/UX/dữ liệu/API được định nghĩa tại chủ đề. Công suất/lịch tại [kế hoạch](../project/planning.md), điều kiện nghiệm thu chung tại [acceptance](acceptance.md), thay đổi phạm vi tại [quyết định](../records/decisions/README.md).
